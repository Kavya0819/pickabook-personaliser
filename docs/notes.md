# Pickabook Personalisation – Notes

## Why Instant-ID?
- No training needed
- Face identity preserved
- Simple API
- Fast for a prototype

## Limitations
- Background may change
- Slow on first request
- Sometimes face is not perfect
- One style only

## v2 Ideas
- Multiple templates
- Loading bar
- Better face crop
- Style selection
- Save history

## Replicate Billing
Instant-ID runs on Replicate’s GPU infrastructure and requires paid billing for API calls. 
For this assignment, the deployed version returns a fallback image instead of a live generation.
